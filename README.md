# Enterpriser

*For those who build.* A digital journal by Allmer Journals (Simon Allmer Entertainment) about how ventures and original work get made, with the **Enterpriser Index**, a free database of businesses worldwide ranked by longevity.

## Run

Static site, no build step. Serve the folder and open `index.html`:

```bash
python3 -m http.server 8742
```

The app renders into `#enterpriser` and uses hash routing (`#/`, `#/index`, `#/index/<uid>`, `#/engine-room`, `#/engine-room/<exhibit>`), so it can be embedded via iframe.

## Files

| File | Purpose |
|---|---|
| `index.html`, `style.css`, `script.js` | The app |
| `engine-room.js` | Engine Room: interactive system models (oil economy), 2D drawing |
| `engine-room-shop.js` | Learning Curve step 1: The Bicycle Shop (thermostat, delays) |
| `engine-room-3d.js` | 3D diorama view of the same model (three.js, loaded on demand) |
| `data.js` | Hand-curated Index entries |
| `data-sp500.js` | S&P 500 entries, generated by `tools/import_sp500.py` (Wikipedia + Wikidata) |
| `schema.md` | Index data model and rules |
| `style-doctrine.md` | Visual and editorial style rules |
