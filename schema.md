# Enterpriser Index — Schema v0.2

The Enterpriser Index is Enterpriser's free, public reference of businesses worldwide.
Linked-data principles (Berners-Lee): every entity has a stable id, facts point to other
entities instead of free text where possible, and every changing fact carries its year,
its sources and how sure we are.

## Admission rules

1. **Five-year rule.** A business must have existed for at least 5 years (founded ≤ current year − 5). No hyped startups.
2. **Global.** No country or industry is favoured. Longevity leads, revenue follows.
3. **No expert scores.** Opinion lives in articles. An entry links to every article that
   mentions it, and an AI summary of those articles stands in for an "expert rating".

## Life and continuity (the lead metric)

`status` is one of:

| status     | meaning |
|------------|---------|
| `alive`    | Still operating. Includes businesses acquired but still operating under their own name, renamed businesses (same entity), and merged businesses whose operations continue in the merged company. |
| `absorbed` | Acquired and dissolved into another business; the name may survive as a brand only. |
| `defunct`  | Ceased operating (bankruptcy, liquidation, closure). |

`age` = (ended year or current year) − founded year. It is calculated, never stored.

## Accuracy levels (per fact, not per entry)

| code     | colour | meaning |
|----------|--------|---------|
| `green`  | green  | Official source (annual report, filing) or 2 sources agree. Note: Wikipedia + Wikidata agreeing counts as green in v0.2, though they are not fully independent. |
| `blue`   | blue   | One credible source |
| `yellow` | yellow | Calculated or estimated (e.g. lifetime headcount average) |
| `red`    | red    | Unverified / tradition / legend |

An entry's overall accuracy is the weakest level among its core facts (founded, status, headcount).

## Statement

Any fact that changes over time is a statement:

```js
{ v: 164000, year: 2024, src: ["s1"], acc: "green", note: "optional" }
```

- `v` value, `year` the year the value describes, `src` source ids (count shown in UI), `acc` accuracy level.

## Entry

```js
"ent-0001-kongo-gumi": {
  uid, label, legal_name, aliases: [],
  ids: { wikidata, lei, ticker, cik },               // links to other databases
  website,                                           // official site (Wikidata P856), null if defunct/unknown
  lists: ["sp500"],                                  // index memberships
  summary,                                           // one sentence, checklist tone
  founded: { year, place, country, acc, src, note },
  lineage,                                           // year of earliest predecessor, if older than `founded`
  status, ended: { year, acc, src } | null,
  events: [ { year, type, text } ],                  // founded | renamed | acquired | merged | relocated | milestone | ended
  founders: [ { name } ],
  hq: { city, country, continent },
  industry: { label, isic, sector },                 // label; ISIC Rev.4 (curated); GICS sector (all)
  ownership,                                         // family | public | holding | subsidiary | cooperative | state | religious
  parent: { label, uid } | null,
  products: [],
  production,                                        // how it's made: method, key IP, know-how
  metrics: {
    headcount: { founding: Statement, current: Statement },
    revenue:   { current: Statement & { unit } }
  },
  sources: { s1: { title, url } }
}
```

### Headcount rule

If both founding-era and current headcount exist, the UI also shows a **lifetime average**
(founding + current) / 2, always marked yellow. It is a "typical size over its life" figure,
never shown as current headcount.

### Founded vs. lineage

`founded` is the year the current business began; ranking uses it. `lineage` is the year of the earliest
predecessor (e.g. AbbVie 2013, lineage 1888 through Abbott). The Index can also sort by lineage.
Open question: for mergers where one side clearly continues (Stora Enso 1288), the curated entry uses the
lineage year as `founded`. Imported entries follow the source's first year until reviewed.

## Data files

| File | Content | Edited |
|---|---|---|
| `data.js` | `ENTERPRISER_INDEX`: hand-curated entries with editorial fields | by hand |
| `data-sp500.js` | `ENTERPRISER_SP500`: S&P 500 constituents ≥ 5 years old | generated by `tools/import_sp500.py` (Wikipedia list + Wikidata via SEC CIK, fallback via Wikipedia article) |

Curated entries win over imported ones (the importer skips tickers listed in `CURATED`).

## Articles (linking)

```js
{ id, title, date, url, mentions: ["ent-…"] }
```

Each entry lists all articles that mention it. Once ≥ 1 article exists, an AI-written
opinion summary is generated from those articles and stored on the entry as
`opinion: { text, generated, articles: [ids] }`.

## Roadmap fields (not yet in v0.1)
